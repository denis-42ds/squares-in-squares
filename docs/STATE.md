# STATE.md — Squares in Squares (обновлено 2026-11-03, конец чата 01)

## Задача
- Kaggle "Squares in Squares": упаковать n единичных квадратов (n=1..1000) в минимальный квадрат со стороной L.
- score(n) = L/sqrt(n) - 1; итог = сумма по n; меньше = лучше.
- Участвую соло. Цель: золото.

## Метрика (подтверждено, детали в docs/metric_notes.md)
- L считается точно (mpmath, 60 dps) из десятичных строк; допусков в L нет.
- Перекрытия: float SAT (tol 1e-8) + интервальная сертификация. Нужен строго положительный зазор; точное касание проходит только для осе-параллельных квадратов (угол ровно "0") с двоично-точными центрами.
- Public скорит все 1000 n. Невалидный пазл = grid ceiling.
- evaluate_single_puzzle(n, rows: list[dict[str,str]]) -> (n, score, L_str | None, reason). L_str с 50 знаками, только для допустимого пазла.
- Kaggle прогоняет сабмит через pandas read_csv -> to_csv; локальный verify эмулирует это по умолчанию (--raw отключает). На sample результат raw и pandas совпал.
- Принято Kaggle: упаковка n=5 с зазором 3e-12; формат id = n(n-1)/2 + square_id.

## Допуски нашего кода
- SEP_EPS = 1e-12 (зазор по оси SAT). Исключение: пары, где у обоих angle == 0.0 и центры кратны 1/1024, допускают зазор 0 (проверка точная).
- Запись: repr(float); угол 0 пишется "0"; угол нормализуется в [0, pi/2), значения у границ (1e-15) прилипают к 0.
- polish: масштаб центров от центроида на 1+d, d стартует 2*max(eps-g, eps), потолок 1e-3. Большие перекрытия не чинит.
- MIN_GAIN = 1e-11: float-префильтр перед гейтом. Решение о записи в best[n] принимается только по точному L из гейта (Decimal), строго меньше текущего.
- Ни одно решение не попадает в best без гейта через vendor/metric.py.

- io.py: format_rows, write_submission (недостающие n = сетка), read_rows (via_pandas), read_submission.

- store.py: data/best/{n:04d}.npz (xya, L str, source), try_update / try_update_many (куски по 32, дозапуск безопасен), push_down_candidate, push_down, total_score; лог runs/updates.log. Корень задаёт SQIN_ROOT (по умолчанию текущая папка).
- cli.py: команда `sqin` (или python -m sqin.cli): baseline, verify FILE [--raw] [--procs], ingest FILE --source TEXT [--no-polish], build [--out] [--verify], status, pushdown [--start].
