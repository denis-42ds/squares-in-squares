# STATE.md — Squares in Squares (обновлено 2026-11-01, после чата 00)

## Задача
- Kaggle "Squares in Squares": упаковать n единичных квадратов (n=1..1000) в минимальный квадрат со стороной L.
- score(n) = L/sqrt(n) - 1; итог = сумма по n; меньше = лучше.
- Цель: золото. Ориентир: топ-1 ~22.0565, #2 ~22.0991, #20 ~22.2107 (на 2026-11-01).

## Метрика (детали в metric_notes.md)
- L считается точно (mpmath, 60 знаков) из десятичных строк; допусков в L нет.
- Перекрытия: float SAT (tol 1e-8) + интервальная сертификация (50..500 знаков). Нужен строго положительный зазор; точное касание проходит только для оси-параллельных квадратов с двоичными центрами.
- Невалидный пазл = grid ceiling (не катастрофа). Фатальны только: нет колонок, n вне [1,1000], n не int.
- Наш допуск: SEP_EPS = 1e-12 (float64-валидатор), запись через repr(float), финальный гейт = локальный evaluate_single_puzzle метрики.
